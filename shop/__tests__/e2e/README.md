# End-to-End Tests для RoyalTick

## 📝 Опис тестів

Цей файл містить E2E тести для основних функцій магазину:

1. **Додавання товару до кошика з вибором розміру** 
   - Перейти в каталог
   - Знайти товар
   - Клікнути "Додати в кошик"
   - Вибрати розмір в модалці
   - Підтвердити додавання

2. **Додавання товару в Улюблені**
   - Перейти в каталог
   - Знайти товар
   - Клікнути кнопку "Додати в улюблені"
   - Перейти на сторінку улюблених
   - Перевірити що товар там з'явився

3. **Перегляд каталогу**
   - Перейти в каталог
   - Перевірити, що товари завантажилися
   - Перевірити видимість цін

## 🚀 Як запустити тести

### Локально на вашому комп'ютері:

```bash
# Перейти в директорію проекту
cd shop

npm test -- --verbose

# Встановити залежності (якщо ще не встановлені)
npm install

# Запустити E2E тести
npm run test:e2e

# Запустити тести з UI модом (з візуалізацією)
npx playwright test --ui

# Запустити тільки один тест
npx playwright test royal-tick-e2e.spec.ts -g "Користувач може додати товар до кошика"

# Запустити тести на конкретному браузері
npx playwright test --project=chromium
```

### У CI/CD (Continuous Integration):

```bash
npm run test:e2e
```

## 🐛 Debugging

Якщо тест падає:

1. **Перевіри, чи запущено `npm run dev`**
   - Тести потребують живого сервера на `http://localhost:3000`

2. **Включи headed mode для візуалізації**:
   ```bash
   npx playwright test --headed
   ```

3. **Збільш timeout'и** якщо сервер повільний:
   - Зміни значення в `test.setTimeout(60000)` на більше

4. **Подивися логи**:
   ```bash
   npx playwright test --debug
   ```

## 📝 Конфігурація Playwright

Основна конфігурація знаходиться в [playwright.config.ts](../../playwright.config.ts):

- **WebServer**: Автоматично запускає `npm run dev`
- **Base URL**: `http://localhost:3000`
- **Timeout**: 120 секунд на запуск сервера
- **Browsers**: Chromium (можна додати Firefox, WebKit)
